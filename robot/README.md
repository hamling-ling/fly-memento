# 実機アプリ（Arduino UNO Q）

Linux 側がカメラと脳とバツ画面、マイコン側が車輪。学習の手順は下と、リポジトリ直下の README にある。

## 動かし方

PC から `arduino@uno-q-1.local` へ SSH の鍵で入る。ボードに `arduino-app-cli` と Docker がある。リポジトリのどこからでも実行できる。

```bash
scripts/deploy_fly-memento.sh
```

- 別のホストへ置くとき: `scripts/deploy_fly-memento.sh arduino@<ホスト名>.local`
- スケッチを必ず作り直すとき: `--rebuild`
- 送るファイルとハッシュだけ見るとき: `--dry-run`（SSH しない）

ボード上の置き場所は `~/ArduinoApps/fly-memento`。`brain/` は `python/brain` に同梱する。アプリだけでは `brain` を import できないためである。Python だけの更新では `.cache` を残し、`app.yaml` か `sketch/` が `~/ArduinoApps/fly-memento/.sketch-hash` と違うとき、または `--rebuild` のときはキャッシュを消してコンパイルする。

手で起動・停止するときは SSH で入る。

```bash
ssh arduino@uno-q-1.local
arduino-app-cli app start ~/ArduinoApps/fly-memento/
arduino-app-cli app stop ~/ArduinoApps/fly-memento/
```

ログは PC で取る。画面に流れ、同じ内容が `logs/fly-memento-日時.log` に残る（`logs/` は git に入らない）。

```bash
scripts/logs_fly-memento.sh
```

止まっているときは 1 秒に 1 行、動いているあいだは 0.1 秒ごと。各行は `red` と `blue` から始まり、`punish`、`avoid`、`mbon`、`ARM`、`LTM`、`pulse`、`drive` で終わる。ボード上で見る場合は `arduino-app-cli app logs ~/ArduinoApps/fly-memento/ --follow --tail 30`。

スマホは同じネットワークから `http://<UNO Q のアドレス>:8000/` を開く。ポートは `app.yaml` の 8000。画面の「バツ」が罰である。赤が見えているあいだに押す。青は罰なし。起動ログに `バツ画面` とこのポートが出る。

カメラは赤を CS+、青を CS− として数える。数え方は fly-car と同じで、門は `python/color_thresholds.json`（赤は色相 322° 以上、彩度 100、明度 120。青は 180–220°、彩度 160、明度 70）。眼の割合が `fraction_floor`（0.05）未満はログには残し、脳には渡さない。色相 0° は赤の紙ではない（このカメラの紙は 340° 付近）。色が無いときの車輪は 0 である。探索の前進が要るときは `config.py` の `EXPLORE_BIAS` を 0.35 にする。パネルが見えているのにパルスが 0 のままなら、`COLOR_GAIN` を上げる。色相 0° や 240° のパネルを数えるときは、JSON の `hue_low` か `hue_high` を広げる。

`No Colon In First Item Of Depfile` と出たら、スケッチのキャッシュが壊れている。`--rebuild` を付けて配置し直す。

チェックアウトのまま画面だけ見るときは `python3 robot/python/main.py --dry`。このときは `brain/` が `robot/` の隣にある。

## 時間

今の圧縮は `python/config.py` の `COMPRESSION = 1`。**1 ロボット秒 = 1 生物分**である。下の秒数はこの値のときのもので、圧縮を 5 にするとロボット側の秒数は 5 分の 1 になる。

間隔の門は 10 生物分、つまり **10 ロボット秒**。LTM の窓もその後の 10 ロボット秒。推奨する休息はシミュレーションと同じ **15 秒**。

画面いっぱいの赤の紙（色相 340°、彩度 220、明度 180）は眼の割合 1.00 で、`fraction_floor` 0.05 より十分上である。画面の中央に、高さ半分・幅 4 割の同じ紙を置いても割合は約 0.27 で、門は越える。色相 0° の真っ赤は門の外で、割合は 0 になる。1.5 秒見せるかどうかは割合を変えない。割合はフレームの埋まりで決まる。

## バツと「周を始める」

「周を始める」は罰の許可ではない。ページを開いた直後は休息で、ログの周とモードは `rest` と `wait` である。この表示はバツを捨てない。

- 赤の紙を見ているあいだのバツは、周の外でも S に入る。その後 ARM が増える。LTM は増えない。
- 青を見せて押しても S は増えない。青は罰なしの色である。
- 暗がり、または色相 0° の赤で押しても、見ていた細胞が無く S は増えない。赤の紙を見せてから 1 秒ほど置いて、まだ見えているあいだに押す。不応期は 1 秒。
- 周を開いているあいだだけ、試行中の忘却が止まる。周の外では S は書かれたあと、時定数 60 生物分（圧縮 1 なら 60 ロボット秒）で薄くなる。

`phi` は振動の位相ではない。疲労で、平常は 0 である。短い休息（10 秒未満）で周を終えたときだけ 1 になり、振動子を弱める。アイドル中の `phi 0.00` は振動が止まっているサインではない。画面の MP1 と MV1 が約 10 秒ごとに 0 付近と 5 付近を往復する。

## 長期記憶が出る押し方

1. 「周を始める」を押す。
2. 赤の紙を約 20 秒見せる。見えてから 1 秒以上たってバツを押し、その後も 1.2 秒おきに押す（約 16 回）。
3. 青の紙を約 20 秒、罰なし。LTM の門には効かない。罰さない色として見せる。
4. 「周を終えて休む」を押し、15 秒待つ。画面が「間隔まであと何秒」から「間隔は足りている」に変わる。10 秒未満で次の周を終えると疲労になり、窓は開かない。
5. 1 から 4 を、合わせて 5 周。

1 周目の終わりでは窓は開かない。前に 10 秒以上の休息が無いからである。2 周目を終えた瞬間に窓が開き、続く休息の最初の 10 秒だけ LTM が増える。増え方は滑らかではなく、MP1 と MV1 が同時に高い 1〜2 秒だけ段が付く。3 周目以降の休息でも、前の間隔が 10 秒以上なら同じ窓が開く。

画面の S / ARM / LTM は 100 個のケニヨン細胞すべての平均である。赤を見た細胞はおおよそ 10 個なので、その細胞の上の痕跡は画面の約 10 倍である。

この 20 秒 × 5 周では、画面の LTM は 1 周目の休息では 0.000 のまま、2 周目の休息でおおよそ 0.02、5 周の終わりでおおよそ 0.11 になる。疲労 φ は 0 のままである。

赤を 1.5 秒、そのあいだにバツを 1 回、続いて青を 1.5 秒、休息 15 秒、それを 5 周でも LTM は増える。1 周目の休息では 0.000、2 周目が終わって約 2 秒後（振動が揃ったとき）に 0.001 ほど乗り、5 周の終わりでおおよそ 0.013 である。

## 増えない押し方

ロボットのループで、赤 1.5 秒・バツ 1 回・青 1.5 秒を 5 回回したときの画面の値は次のとおり。赤は上の紙の色で、眼の割合は 1.00 である。

| 押し方 | S | ARM | LTM | phi |
|---|---:|---:|---:|---:|
| 周のボタンを押さない | 0.018 | 0.009 | 0.000 | 0.00 |
| 周を閉じ、15 秒休む（5 周の終わり） | 0.006 | 0.000 | 0.013 | 0.00 |
| 周を閉じ、2 秒だけ休む | 0.023 | 0.007 | 0.000 | 1.00 |

周のボタンが無いときは状態が休息・待機のまま、ショックは 5 回入り、適格だった細胞は 0.8 ほど立つ。LTM だけが 0 のままである。休息 2 秒は 2 周目の終わりで疲労が 1 になり、窓は開かない。

## 状態のフィールド

`/state` のこれまでのキーはそのままである。足したものは `rounds`（閉じた周の数）、`rest_s`、`gate_s`、`win_left_s`、`gap_ready`、`mp1`、`mv1`、`shock_elig`（直前のバツのとき、いちばん適格だった細胞）、`note`（画面の案内）である。
